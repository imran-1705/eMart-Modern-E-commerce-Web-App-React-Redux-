🛒 eMart – Modern E-Commerce Web Application (React + Redux)
eMart is a fully responsive and dynamic e-commerce web application built using React for the UI and Redux for efficient global state management.
It simulates a real online shopping experience with features like product listing, cart system, filtering, and basic authentication flow.
This project demonstrates clean component structure, centralized state handling, routing, and real-world e-commerce functionality.

✨ Features
⚛️ React-based UI with reusable components
🟥 Redux for global state management
📦 Product listing with dynamic data rendering
🛒 Add to Cart / Remove from Cart
🏷️ Filter & category selection
🔐 User authentication UI (Login/Register simulation)
📱 Fully responsive design
🚀 Fast and scalable architecture

📦 Installation & Setup
Follow the steps below to run the project locally:
1️⃣ Clone the repository
git clone https://github.com/imran-1705/eMart-Modern-E-commerce-Web-App-React-Redux-.git

2️⃣ Navigate into the project
cd eMart-Modern-E-commerce-Web-App-React-Redux-

3️⃣ Install dependencies
npm install

4️⃣ Start the development server
npm start
